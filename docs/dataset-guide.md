# 🗺️ Dataset Guide & Coordinate Systems

## Supported Formats
1. **Cadastral Boundary Data**:
   - GeoJSON (`.geojson`) or Shapefiles (`.shp`) in standard `WGS84 (EPSG:4326)` or UTM zones (e.g., `EPSG:32643` for North India).
2. **3D Point Cloud Data**:
   - ASPRS LAS (`.las`) or compressed LAZ (`.laz`) format with RGB/Intensity values and georeferenced coordinates.
3. **Deed & Land Title Records**:
   - CSV or JSON structured land ownership records including khasra/survey numbers and deed deeded areas.
